# AutoParts Pro commercial roadmap

Delivered: desktop source project for a single shop, barcode POS, full parts details, vehicle fitment, customer profiles with multiple structured cars, workshop visit/oil history and due reminders, inventory, purchases, credit, returns, warranty records, recovery codes, reports and optional cloud AI.

Before selling broadly: test Windows installation, driver/scanner/printer combinations, sign a packaged installer, define support/updates/backup ownership, verify licenses, perform independent security review, and pilot with a real shop. No signed standalone EXE is included; Python and first-run desktop-engine installation are required.

Future work: licensed OEM catalog/VIN decoding, labour/service-charge invoices, automatic opt-in customer reminders, supplier returns, parts serial/batch tracking, quotation-to-sale conversion, expenses/full accounting, multi-branch sync, full electronic service warranty processing and applicable certified tax/payment integrations. Current fitment/specification/origin data is shop-entered, not automatically verified.

Cloud AI requires the owner's API key and usage charges; the included offline assistant uses deterministic rules. No income, commercial readiness or vehicle-fit guarantees are made.
