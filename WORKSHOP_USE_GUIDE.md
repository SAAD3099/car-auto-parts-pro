# AutoParts Pro — asan istemal guide

## 1. Customer aur uski gaari add karein

Customers kholein > Add customer. Naam aur phone likhein > Save. Customer Profile mein Add car dabayein. Make/company, model, registration number aur zaroorat par year, engine, chassis likhein > Save. Ek customer ki multiple gaariyan add ho sakti hain. Har gaari ki visit/oil history alag hai. Profile mein Edit car se detail badal sakte hain.

## 2. Customer dobara aaye to visit save karein

Customer search karein > Profile > sahi gaari ke neeche New visit. Visit ki asal date/time, meter reading aur kya kaam kiya likhein. Mechanic aur extra notes optional hain. Purani visit bhi enter kar sakte hain, lekin meter reading history ke mutabiq honi chahiye. Completed visit future date par save nahi hoti.

Oil nahi badla to Oil change No rakhein. Is se pehle ka oil record delete nahi hota. Oil badla ho to Yes karein; brand, grade, litres aur filter detail likhein. Next oil date/time **ya** next meter reading dein; dono bhi de sakte hain. Interval vehicle manual/workshop ke mutabiq khud set karein. Save visit dabayein.

## 3. Oil aur parts ka bill banayein

Visit save hone ke baad Parts ka bill banao dabayein. Customer aur gaari automatically select hote hain. Barcode scan karein ya product search karein, quantity set karein, checkout/payment karein. Receipt visit ke saath link hoti hai. Pehle se usi customer ka correct bill ho to visit form mein existing receipt number attach kar sakte hain.

**Visit mein oil litres likhna stock kam nahi karta aur payment record nahi banata.** Stock/payment normal parts bill se record hota hai. Misal: 4-litre packed bottle product Piece unit mein ho to bill quantity 1; loose oil Litre unit mein ho to bill quantity 4. Workshop work notes service record hain; labour invoice is version mein shamil nahi.

## 4. Last visit aur next oil dekhein

Customer Profile ki car card par last visit ki date/time, kaam aur last recorded kilometre milte hain. Last oil change ki alag date/time, brand/grade/litres aur next oil schedule bhi milta hai. Visit details se poora record kholein aur service card print karein.

Workshop & oil > Oil reminders mein saved schedules milte hain. Date aa jaye **ya** latest recorded kilometre next limit tak aa jaye to Due dikhta hai. Agle 7 din ya 500 km ke andar ho to Soon dikhta hai. Mileage sirf saved visits se milti hai; live tracking nahi. Phone detail dekh kar customer ko khud contact karein; automatic SMS nahi jata.

## 5. Buying price, sale price aur pieces

Parts > Add spare part: naam, buying cost, selling price, company, made in, barcode/shop code aur opening stock dein. Barcode na ho to generated shop code use kar sakte hain. Part/OEM number, rack, warranty aur fitment optional details mein hain.

Buying cost purchase entries ke baad weighted average hoti hai. Selling price customer ki per-unit price hai. Available abhi ka stock hai. Sold net = sold quantity minus returned quantity; original sold/returns detail mein bhi milte hain. Cashier ko buying cost nahi dikhayi jati.

Naya maal aaye to Purchases mein supplier, product, quantity, actual buying rate aur payment save karein. Existing stock ka correction Count/stock adjustment se reason ke saath karein. Stock count ko normal sale/purchase ki jagah use na karein.

## 6. Product search

Upar search bar mein naam, barcode, company ya part number likhein. Result par click karein: price, stock, sold, made in, company aur saved specifications milti hain. Vehicle Finder More tools mein hai; fitment shop ke entered data par based hai.

## 7. Ghalat record aur returns

Ghalat workshop visit ko manager/admin Visit details se cancel kar sakta hai; record audit/history mein rehta hai. Sahi visit dobara enter karein. **Visit cancel karne se linked bill cancel/refund nahi hota.** Parts refund ke liye Sales mein original receipt khol kar normal return karein; stock aur net-sold count update honge.

## 8. Password, backup aur sharing

Login par Forgot username/password mein private recovery card ka code dein. Password reset par naya recovery code save karein; purana code expire hota hai. Admin staff recovery kar sakta hai. Settings > Download backup regularly use karein. Recovery card aur customer database private rakhein.

## 9. Purana software update karein

Purane app se backup download karein. Naya ZIP **alag folder** mein extract karein; purana folder delete/overwrite na karein. Naya app band rakhein aur naya account na banayein. IMPORT_OLD_BACKUP.vbs kholein > backup file choose karein > import. AutoParts Pro.vbs se open karein aur purane credentials use karein. Existing shop wale target mein import refuse hoga. Source backup unchanged rehta hai. Imported free-text car ko Edit car se complete karein.

More tools mein Settings, Warranty desk, Reorder aur Assistant milte hain. Billing/workshop offline chal sakte hain; Cloud AI optional hai aur apni API key/model/internet use karta hai.
